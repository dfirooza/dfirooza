# Hi, I'm Daniel Firoozabadi 👋

## About Me

I'm an engineering student at **UC Berkeley** interested in software engineering, applied AI, and intelligent systems.

Most recently, I worked as a **Software Engineering Intern at Capital One**, where I built retrieval and agent-based infrastructure for a large-scale ERP migration. My work included developing a **RAG and LangGraph-based reconciliation agent** over multi-million-row financial datasets, along with evaluation pipelines for measuring system reliability and accuracy.

Outside of industry, I've worked on projects involving **agentic AI security testing, computer vision, robotics, and full-stack development**. I enjoy taking ambiguous technical problems and turning them into practical, reliable systems.
